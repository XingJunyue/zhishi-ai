# 知时 AI · Zhishi AI

知时（[XingJunyue/zhishi](https://github.com/XingJunyue/zhishi)）的 **AI 版**：同一张课表，加上 AI 截图识别和能帮你动手的 AI 助手。和知时是两个独立的应用（包名 `com.zhishi.timetable.ai`），可以同时安装，数据、设置、提醒和小部件互不影响。AI 用你自己的接口（任何 OpenAI 兼容服务：各家云或中转站），没有自营后端、没有内置密钥。安装包在本仓库的 [Releases](https://github.com/XingJunyue/zhishi-ai/releases)（tag `ai-N`）。

> 好雨知时节，当春乃发生。——杜甫《春夜喜雨》

一张安静的安卓课表。导入一次，每天打开就知道现在、下一节上什么。

## 功能

- **一周课表**：左右滑切换周，点空格加课、点课块修改；今天一列和「现在」的时间线高亮，顶部一条显示正在上 / 下一节和剩余时间。
- **待办**：作业、考试、要交的东西，可设截止时间、关联课程、到点提醒；按今天 / 即将 / 已完成分组，滑动删除，跟课表一起备份。
- **日历**：按月看哪天有课、哪天有待办，点一天列出当天的课和待办。
- **课程标签**：重要 / 普通 / 水课，只是显示在课块和小部件上的标签（可分别关掉），不做任何限制。
- **AI 助手**：底部导航条的 ✦ 打开半屏面板（可拖到全屏），用一句话加课 / 改课 / 挪课 / 删课、设开学日期和每节时间、加待办（截止、提醒）/ 完成 / 置顶 / 删除、换皮肤和轮换收藏、调小部件外观和显示设置、打开页面，也能问「明天有什么课」。所有改动先出前后对比的确认卡片，点「确认」才写入，最后一批可撤销。
- **AI 识别截图**：课表截图发给你设置的看图模型，认出课名、老师、教室、星期、节次、周次、单双周，进导入预览选覆盖或追加（替换了原来的本机 ML Kit 识别）。
- **教务导入**：输入学校名搜索（收录一千六百多所学校的教务入口），内置浏览器登录后一键导入。专用解析：东北大学（金智，真实账号验证过）、正方、强智、新 / 旧 URP、树维 eams、青果、超星、南软；其他走通用表格识别。除东大外都只用样例页面测过。
- **其他导入**：日历订阅链接（Canvas、Moodle、学校课表系统的 iCal）、.ics 文件、系统日历、Excel / CSV（含 Workday、Banner 等选课清单）、保存的教务网页、AI 截图识别、课表备份（也认「留白」导出的备份）。
- **学期设置**：开学日期、这周第几周、总周数、周末、非本周的课、每节课上下课时间。
- **桌面小部件**：4×2 和 2×2，正在上的课（课间是最近的下一节）+ 下一节，没课是一张白卡；颜色跟着皮肤和深浅色走。
- **六套插画皮肤**：春雨（默认）、宣纸、青瓷、暮山、夜航、樱，每套都有浅色和深色的整屏插画，可跟随系统；底部导航：课表 / 待办 / 日历 / 我的。
- **六种语言**：简体中文、English、Français、日本語、한국어、Deutsch、Español。
- 新手教程和每个版本的「新功能」指引；应用内更新（只从本仓库 zhishi-ai 的 Releases 下载）。

课表、待办和设置都存在手机上，没有自营服务器；只有使用 AI 功能时，截图、你发的消息和回答需要的课表 / 待办内容会发给你在「AI 设置」里填的服务商。API Key 用 Android Keystore 加密存在本机。权限只有网络（教务导入、订阅链接、检查更新）、读日历（「从日历导入」时才申请）、安装更新包，以及待办提醒用的通知（第一次打开提醒时才申请）、闹钟和开机重排提醒。

## 构建与发布

没有本地构建要求，GitHub Actions 负责：推到 `main` → 单元测试 → 构建 → 模拟器冒烟测试（截图发到 `ci-shots` 预发布）→ 发布 release `ai-N`（`zhishi-ai-N.apk`）。其他分支用 workflow_dispatch 跑，发 prerelease 预览包。详见 [AGENTS.md](AGENTS.md)。
